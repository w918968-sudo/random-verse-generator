## v2.1 — 内容扩展（流量优先，2026-10-23 规划中）

> **✅ 已完成并上线（2026-10-23）**：T1–T13 全部实现、构建/测试全绿、已部署。逐项 commit 与要点见 backlog「v2 迭代」段 + 项目记忆 `project-status.md`。

目标：**先把流量做起来**。用纯静态内容页吃长尾搜索，同时把经文库补满、补强 v1。

数据决策（已锁定）：
- 21 关键词（8 主题 + 13 场景）× **30 条**；精选库 155 → 约 330–380 条。每关键词内部不重复，**跨关键词允许复用**。
- 数据模型加 `occasions[]`（与 `themes[]` 分开）：8 主题喂首页生成器，13 场景喂落地页。
- 13 场景 slug：anxiety、fear、encouragement、healing、forgiveness、patience、new-beginnings、grief、money、marriage、birthday、work、friendship。
- 生日（birthday）允许用非主流经文凑满 30；策展由 Claude 全做，用户只过目。

四阶段（详见 backlog T1–T13）：
- **阶段 A 数据地基**：T1 `occasions` 字段 → T2 8 主题补 30 → T3 13 场景补 30
- **阶段 B 内容页（主线，吃流量）**：T4 13 场景落地页 → T5 诗篇线 → T6 榜单/精选页
- **阶段 C 留存/互动**：T7 读经计划 → T8 相关经文 → T9 可嵌入每日经文组件
- **阶段 D 体验补强**：T10 反思问题 → T11 收藏增强 → T12 阅读体验 → T13 本地读经打卡

关键路径：T1 → T2 → T3 → T4 → T5 → T6；T7–T9 可并行；T10–T13 收尾。
