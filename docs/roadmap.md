## v2.0 — 功能扩展（探索性，P3）

目标：从「随机工具」走向「每日伴随 / 内容站点」。**部分项目超出当前纯静态边界**，动工前先看 [boundaries.md](boundaries.md)。

- 每日经文（Verse of the Day，日期确定性种子，SEO 友好）
- 经文收藏（localStorage，无账户）
- 全章浏览 / 关键词搜索（可能需打包更多章节或引入后端）
- 多译本（KJV 等公版，需许可证审查 + 数据管线扩展）
- 各主题独立 SEO 落地页（per-theme SEO pages，v1 排除清单）
- 云端神经 TTS（感情化朗读，升级 B-13 的 Web Speech；2026-10-17 用户提出）

## 不做（明确排除，除非重新立项）

- 用户账户、登录、云端收藏
- 用户生成内容 / 评论
- 服务端随机或任何服务端状态
